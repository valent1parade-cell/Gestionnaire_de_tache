# Gestionnaire de Tâches 

Projet réalisé dans le cadre du TP React de gestion de tâches.

## 👥 Binôme
- **Maxime Noel**
- **Valentin Parade**

## 🚀 Fonctionnalités
- **Ajout de tâches** avec validation (refus des entrées vides ou remplies d'espaces).
- **Modification du statut** (marquer une tâche comme faite / en cours).
- **Suppression** de tâches individuelles.
- **Filtrage dynamique** : affichage par filtres (*Toutes*, *En cours*, *Terminées*).
- **Compteur automatique** des tâches restantes (gestion du pluriel et des cas particuliers).
- **Actions globales** : tout marquer comme fait ou nettoyer les tâches terminées.
